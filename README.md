Weather Data Pipeline

A beginner-friendly data engineering project that extracts real-time weather data from the OpenWeatherMap API, processes it, and stores it in a SQLite database for analysis

Project Overview

This project implements a complete ETL (Extract, Transform, Load) pipeline that:

    Extracts current weather data for multiple cities using the OpenWeatherMap API

    Transforms raw JSON data into a clean, structured format with additional derived features

    Loads processed data into a SQLite database for persistent storage

    Analyzes stored data with basic statistics and visualizations

- OpenWeatherMap API → Python Script → SQLite Database → Simple Analysis/Visualization
